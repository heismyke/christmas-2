# Image generation

Created using the built-in image generation tool. Compressed WebP assets are in `public/images/`.

## hero.webp

Use case: product-mockup. Wide landscape 16:9 cozy sophisticated Christmas interior photograph. Wrapped ivory and burgundy gifts, handmade cream ceramic vase, warm amber candle on oak table near a Christmas tree with restrained red ribbons and warm fairy lights. Main objects at right, dark pine green shadowed negative space at left for website headline. Editorial natural textures, warm window light.  Photorealistic materials and realistic proportions. No people, no text, no numbers, no logos, no watermarks. One finished photograph.

Product images reuse the previously generated Maison Merci collection: 1.webp = coffret-merci, 2.webp = bougie-cedre, 3.webp = vase-gres, 4.webp = serviettes-lin, 5.webp = planche-acacia, 6.webp = coffret-epices. Original prompts are in the included SOURCE-IMAGE-PROMPTS.md.
